What happens to each message

  1. ReceiveMessage arrives at the webhook
  2. ClassifyPrice, doctor, timing, appointment, emergency…?
  3. RetrieveFind facts in the clinic knowledge base
  4. DraftWrite an answer using only those facts
  5. VerifyCheck prices, safety and confidence
  6. RouteAuto-reply, ask for approval, or escalate
